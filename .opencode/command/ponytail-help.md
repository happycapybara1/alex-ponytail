description: Quick reference for ponytail levels and commands
---

Show the ponytail quick reference. Change nothing: do not switch mode or write flag files. Levels: /ponytail lite (build what was asked, name the smaller option in one line), /ponytail (full, the default: the smallest complete change, a check where the logic needs one, one line on what was skipped and any risk), /ponytail ultra (also push back on the request before building). Commands: /ponytail-review (review the current changes), /ponytail-audit (review the whole repo, ranked), /ponytail-debt (list shortcut: comments as a debt ledger), /ponytail-help (this card). Turn off with 'stop ponytail' or /ponytail off; back on with /ponytail. Default level is full; change it with the PONYTAIL_DEFAULT_MODE environment variable (off|lite|full|ultra) or ~/.config/ponytail/config.json (Windows: %APPDATA%\ponytail\config.json) containing {"defaultMode": "lite"}; the variable wins over the file. Docs: https://github.com/happycapybara1/ponytail-alex
